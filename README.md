# York

York is a 2d terminal game which runs on your windows terminal  , its like minecraft but in 2d terminal ! and yeah it also has story ! .

i built it from scratch in c++ language with only c++ standard libraries ! .

---

## Why This Game is Actually Insane

It has infinite procedurally generated worlds with caves , hills ,ore viens etc..

It uses perlin noise and fractional brownian motion for generating realistic worlds

You can break blocks like- grass , stone ,iron ,gold ,diamond etc .And build your own world !

And yeah u can also use cheats through pause menu ! . u can increase your speed , go in spectate mode to explore the world , and also get diamnds !.

I implemented a uniqe way to manage windows , each window has its own screen and all window are being stored in a stack ! , and the top most window in stack will be loaded for output !

And all of these things just in a terminal game !
